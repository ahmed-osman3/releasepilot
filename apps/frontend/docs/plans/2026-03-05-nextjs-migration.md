# Next.js Migration Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the TanStack Start app with a Next.js App Router app while preserving all existing product routes, APIs, auth behavior, and core workflows.

**Architecture:** The migration keeps the current domain logic and database layers, but swaps runtime/framework boundaries: TanStack routes and server functions are replaced by Next App Router pages/layouts and route handlers. Shared server services and auth utilities are extracted so both server components and route handlers can use them consistently.

**Tech Stack:** Next.js App Router, React 19, TypeScript, Better Auth, Drizzle ORM, PostgreSQL, TanStack React Query, Tailwind CSS
